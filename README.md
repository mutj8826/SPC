# คลิปคอนเทนต์ "รถโดนชนท้าย" (Honda HR-V)

คลิปแนวตั้ง 1080x1920 (9:16) สำหรับลง TikTok / Reels / Shorts
เล่าความเสียหายจากการโดนชนท้ายทีละจุด โดยมี **ลูกศรเคลื่อนไหวชี้ตรงตำแหน่งที่โดนชน** ของทุกภาพ

- ไฟล์คลิป: `out/rear_end_collision.mp4` (23.6 วินาที, 30 fps, H.264 + แทร็กเสียงเงียบ)
- ภาพต้นฉบับ: `assets/`
- สคริปต์สร้างคลิป: `make_clip.py`

## องค์ประกอบในคลิป

| ส่วน | รายละเอียด |
|---|---|
| ฉากเปิด | หัวเรื่อง "รถโดนชนท้าย" + ลูกศรชวนดูต่อ |
| 5 ฉากความเสียหาย | ภาพจริง + ลูกศรสีเหลืองชี้จุดที่ชน (มีจังหวะเด้ง) + วงพัลส์สีแดงที่จุดกระแทก + กรอบไฮไลต์บริเวณเสียหาย + วงซูมขยายให้เห็นรอยชัด ๆ + คำบรรยายไทย |
| ฉากปิด | ย้ำให้ถ่ายเก็บครบทุกจุดก่อนแจ้งเคลม |
| อื่น ๆ | แถบบอกลำดับจุด 1–5 ด้านล่าง, เฟดข้ามฉาก 0.35 วิ |

จุดที่ชี้ในคลิป

1. ฝาท้ายฝั่งขวา — สีครูดเป็นรอยขาวยาว
2. มุมกันชนหลังด้านล่าง — พลาสติกยับ ย่นเป็นรอยพับ
3. คิ้วดำใต้ฝาท้าย — ครูดยาวตลอดแนว สีลอกเป็นคราบขาว
4. แผงกันชนหลัง — ผิวสีด้าน มีรอยถลอกทั่วแผง
5. เหนือโลโก้ HR-V — รอยขูดลึกเป็นแนวเส้นถี่

## ปรับตำแหน่งลูกศร / คำบรรยาย

แก้ที่ตัวแปร `SCENES` ใน `make_clip.py` โดยพิกัดทุกค่าเป็น **สัดส่วน 0–1 ของภาพต้นฉบับ**

```python
dict(
    file="01-rear-right-scrape.jpg",
    head="ฝาท้ายฝั่งขวา",                     # หัวข้อจุดที่ชน
    caption=["บรรทัดที่ 1", "บรรทัดที่ 2"],    # คำบรรยาย
    focus=(0.451, 0.305),                     # ปลายลูกศร = จุดที่โดนชน
    box=(0.330, 0.195, 0.600, 0.425),         # กรอบไฮไลต์ (x0, y0, x1, y1)
    tail=(240, 250),                          # ทิศ/ความยาวหางลูกศร (พิกเซลบนเฟรม)
)
```

- `focus` ขยับปลายลูกศรและวงพัลส์ รวมถึงจุดกึ่งกลางของวงซูม
- `tail` เป็นเวกเตอร์จากปลายลูกศรไปหาหาง เช่น `(240, 250)` = ลูกศรมาจากด้านล่างขวา ชี้ขึ้นซ้าย
- ความยาวฉากปรับที่ `SCENE_DUR` / `TITLE_DUR` / `OUTRO_DUR` และความเร็วเฟดที่ `XFADE`
