- **เปิดใช้งาน:** ดาวน์โหลด `index.html` แล้วดับเบิลคลิกเปิดในเบราว์เซอร์ได้เลย (ไม่ต้องต่ออินเทอร์เน็ต)
- **ข้อมูลชุดปัจจุบัน:** 113 SO ณ 18 พ.ย. 2026 เวลา ~11:00 น.

> ⚠️ repo นี้เป็น **สาธารณะ** ไฟล์ `index.html` และโฟลเดอร์ `data/` มีชื่อลูกค้า ชื่องาน และยอดสั่งจริง ใครมีลิงก์ก็เห็นได้
> ถ้าต้องการปิด ให้ไปที่ Settings → General → Danger Zone → Change visibility → Private

## โครงสร้างโฟลเดอร์

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `index.html` | ตัวแอปที่ build แล้ว (เปิดใช้งานไฟล์นี้) |
| `build_app.py` | **ซอร์สของแอปทั้งหมด** (HTML + JavaScript + กฎเครื่องจักร) → สร้าง `index.html` |
| `proc.py` | แปลงผลคิวรี `data/rows.txt` + `data/routes.txt` → `data/data.json` |
| `data/` | ข้อมูลงานจาก ENPRO และ `capacity_master.xlsx` (กำลังผลิตเครื่องจักร) |
| `sql/` | คิวรีที่ใช้ดึงข้อมูลจาก ENPRO (ฐาน ENPDS06-01) |
| `tests/test_plan.js` | ตรวจแผนอัตโนมัติ: ไม่ทับ · ไม่คร่อมขั้นตอน · ไม่ก่อนรับงาน · ไม่เว้นว่างโดยไม่จำเป็น |

## หลักการจัดตาราง (อัตโนมัติ)

ระบบแตกทุก SO เป็นทุกขั้นตอนตามเส้นทางผลิต แล้วจัดพร้อมกันทั้งโรงงาน (ฟังก์ชัน `planAll` ใน `build_app.py`)

1. เครื่องเดียวกัน **ห้ามมีงานทับกัน** (LA-M1 กับ LA-M2 นับเป็นเครื่องเดียว เปิดได้ทีละเครื่อง)
2. ขั้นถัดไปของ SO เริ่มได้ **หลังขั้นก่อนเสร็จเท่านั้น** (ไม่คร่อม)
3. ขั้นแรก **ไม่เริ่มก่อนเวลา DC รับงาน** และไม่ย้อนหลังเวลาดึงข้อมูล (`HORIZON`)
4. เครื่องว่างเมื่อไร ถ้ามีงานพร้อมเข้า **ต้องหยิบเข้าทันที** (ไม่เว้นว่าง) — ช่องว่างที่ยังเห็นคือช่วงที่ไม่มีงานพร้อมจริง
5. ถ้าหลายงานพร้อมพร้อมกัน ให้ **วันส่งลูกค้าก่อน** ได้ก่อน
6. ปรับเวลา/ย้ายเครื่องเอง (ลากแท่ง หรือกรอกในหน้ารายละเอียด) → ระบบเลือกได้เฉพาะเครื่องที่งานลงได้ เลื่อนไม่ให้ทับงานที่ล็อกอื่น แล้วจัดคิวที่เหลือใหม่
7. เวลาทำงาน: กะเช้า 08:30–17:30 (พัก 12:00–13:00) · กะดึก 20:00–05:00 (พัก 00:00–01:00, 05:00–05:30)

มุมขวาของ Gantt มีป้าย **"ตรวจแผน"** บอกทันทีว่ามีงานทับ/คร่อม/ก่อนรับงานหรือไม่

> หมายเหตุ: การปรับเวลา/กดยืนยันในแอป **บันทึกอยู่ในเบราว์เซอร์ของแต่ละคน** (ไม่แชร์ข้ามเครื่อง)
> ถ้าจะให้แผนที่ปรับแล้วเป็นของกลาง ต้องแก้ข้อมูลใน repo แล้ว build ใหม่

## จะแก้อะไร แก้ตรงไหน (ใน `build_app.py`)

| อยากแก้ | ค้นหาคำนี้ |
|---|---|
| กำลังผลิตเครื่อง (ใบ/ชม.) | `const CAP=` |
| เครื่องในแต่ละแผนก | `const POOL=` |
| ขนาดงานที่เครื่องรับได้ (ใหญ่สุด/เล็กสุด) | `const MSIZE=` |
| กฎเฉพาะงาน ขั้นแรก (เช่น อาบบิสเตอร์→BP-A2) | `function forcedPool` |
| กฎเฉพาะงาน ขั้นถัดไป | `function stepPoolFull` |
| ไดคัท: ยอด ≥3000 → DC-A, ไม่เกิน 17x23 → DC3 | `function dcSub` และ `function dcSubOf` |
| เวลากะ/ช่วงพัก | `function daySegs` |
| เวลาเริ่มวางแผน และวันที่ของข้อมูล | `const HORIZON=` และ `const DATA_ASOF=` |
| ลำดับความสำคัญของงาน | `pri:` ใน `function planAll` |

## อัปเดตข้อมูลใหม่จาก ENPRO

1. รัน `sql/pull_jobs.sql` แล้วบันทึกผล (คอลัมน์ `line`) เป็น `data/rows.txt` — 1 บรรทัดต่อ 1 แถว
2. รัน `sql/pull_routes.sql` แล้วบันทึกผลเป็น `data/routes.txt`
3. แก้ `HORIZON` และ `DATA_ASOF` ใน `build_app.py` เป็นเวลาที่ดึงข้อมูล
4. รันคำสั่ง (ต้องมี Python 3 และ Node.js)
   ```bash
   python proc.py          # สร้าง data/data.json
   python build_app.py     # สร้าง index.html
   node tests/test_plan.js # ต้องขึ้น RESULT: PASS
   ```
5. commit แล้ว push
